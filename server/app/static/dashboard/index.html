فحص البرامج غير الموقَّعة والمتخفّية على جهاز النظام

فحص قراءة فقط - لا يوقف أي عملية ولا يحذف أي ملف ولا يرفع أي بيانات لأي خدمة خارجية. كل نتيجة تُعرض بدرجتها وكل أسبابها كاملة لتقرر بنفسك؛ لا يوجد هنا أي زر "إيقاف/عزل" تلقائي.

التدقيق الأمني لإعدادات الحماية

تدقيق قراءة فقط لإعدادات حماية جهازك (Defender، جدار الحماية، UAC، LSA، SmartScreen...). النظام لا يُعدّل أي إعداد تلقائيًا. لكل نقطة ضعف يظهر أمر الإصلاح الموصى به — انسخه ونفّذه بنفسك في PowerShell كمسؤول إن قررت، ومعه أمر التراجع. بعض البنود تتطلب خطوات يدوية (BIOS، واجهة Windows) لا أمر جاهز لها.

الأجهزة/الشبكات الموثوقة

قائمة توثيقية فقط لمساعدتك على تذكّر شبكاتك الموثوقة (منزل/شركة). هذا النظام لا ينشئ ولا يعدّل أي قاعدة جدار حماية فعلية على أي جهاز - إن أردت إنشاء قاعدة سماح فعلية في جدار حماية ويندوز، استخدم الأمر النموذجي الذي يظهر لك بعد الإضافة، ونفّذه بنفسك كمسؤول.
