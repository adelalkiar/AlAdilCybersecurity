# ربط منهج أمنية البيانات (المرحلة الثالثة) بالنظام

هذا الجدول يربط كل بند من منهج مادة الأمن السيبراني بالملف/الدالة التي
تغطّيه في نظام AlAdil Cybersecurity، وكيف تعرضه/تختبره في المناقشة.

المبدأ العام للنظام: **الفحص للقراءة فقط**، وأي إجراء (حظر، تحصين، عزل)
خطوة منفصلة تُعرض كأمر نصّي يؤكّده المستخدم وينفّذه بنفسه، وقابلة للتراجع.

---

## الفصل 1 — المفاهيم الأساسية (السرية/السلامة/التوفر، المساءلة، عدم الإنكار)

| البند | الملف/الدالة | كيف أعرضه/أختبره |
|---|---|---|
| السرية (تشفير عند السكون) | `server/app/core/crypto.py` (`EncryptedString`, Fernet/AES) | مفاتيح التراخيص وبيانات العملاء تُخزَّن مشفَّرة في قاعدة البيانات |
| السلامة (سلسلة تجزئة) | `shared/integrity.py` (`append_entry`, `verify_chain`) | `pytest tests/test_integrity.py` — يكشف التعديل/الحذف/إعادة الترتيب |
| عدم الإنكار (توقيع رقمي) | `server/app/services/license_service.py` (`sign_payload`/`verify_payload` Ed25519) | زر «تحقق من التوقيع» في لوحة «المساءلة والتحقق»، أو `GET /api/scans/{id}/verify` |
| المساءلة (سجل تدقيق موثوق) | `shared/authorization_gate.py` + `server/app/core/audit_chain.py` | لوحة «المساءلة والتحقق» ← «تحقق من سلاسل التدقيق» |

## الفصل 2 — مراحل الاختراق وأنواع المخترقين

| البند | الملف/الدالة | كيف أعرضه/أختبره |
|---|---|---|
| مراحل الاختراق (اختيار الهدف/الاستطلاع/الهجوم) | `shared/vuln_db/attack_phase.py` (`classify_attack_phase`) | افتح تفاصيل جهاز مشبوه ← «خط زمني للمهاجم»؛ `pytest tests/test_attack_phase.py` |
| أنواع المخترقين (قبعة بيضاء/سوداء/رمادية) | لوحة «القبعة البيضاء» + `shared/authorization_gate.py` | زر «القبعة البيضاء» يشرح النوعين ويبيّن ضمانات النظام |

## الفصل 3 — الجدران النارية

| البند | الملف/الدالة | كيف أعرضه/أختبره |
|---|---|---|
| أنواع الجدران (تصفية حزم/مستوى تطبيق/فحص حالة) | `agent/app/discovery/firewall_audit.py` (`classify_rule`) | لوحة «الجدار الناري» ← «تصنيف القواعد»؛ `pytest tests/test_firewall_audit.py` |
| مستوى الدائرة/النموذج المرجعي (غير منطبقين) | `firewall_audit.py` (`general_notes`) | لوحة «الجدار الناري» ← «ملاحظات منهجية» |
| حدود الجدار الناري | `firewall_audit.py` (`boundaries`) | لوحة «الجدار الناري» ← «حدود الجدار الناري ← الوحدة المغطّية» |
| سياسات الوارد/الصادر والقواعد الخطرة | `firewall_audit.py` (`evaluate_firewall`) | تنبيهات اللوحة (ملف مطفأ، Any→Any، منفذ عام عالي الخطورة) |

## الفصل 4 — التشفير الكلاسيكي وتحليل الشفرات

| البند | الملف/الدالة | كيف أعرضه/أختبره |
|---|---|---|
| الإبدال (قيصر/عام) | `shared/crypto_lab/classic_ciphers.py` | لوحة «مختبر التشفير» ← تشفير/فك؛ `pytest tests/test_crypto_lab.py` |
| التبديل (العمودي) | `classic_ciphers.py` (`columnar_encrypt/decrypt`) | نفس اللوحة باختيار «تبديل عمودي» |
| تحليل الشفرات (كسر بلا مفتاح) | `shared/crypto_lab/weak_encoding.py` (`break_caesar`, `scan_value`) | لوحة «مختبر التشفير» ← «كاشف الترميز الضعيف» |
| هجمات تحليل الشفرة الخمسة | لوحة «مختبر التشفير» ← «أنواع هجمات تحليل الشفرة» | يشرح لماذا يقاومها AES-GCM و Ed25519 |

## تشغيل كل الاختبارات

```bash
.venv/Scripts/python.exe -m pytest tests/ -q
```

كل وحدة جديدة لها اختباراتها النقيّة (بلا شبكة/نظام)، فتعمل على أي جهاز.
