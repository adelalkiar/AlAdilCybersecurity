# الهوية البصرية — AlAdil Cybersecurity

مستخرجة من شعار الشركة الأم الموجود في `logo/`:
- `logo/AdilCompanyWithFill..png` — الشعار الأساسي (كبسولة كحلية، رمز أبيض) — يُستخدم على خلفيات فاتحة.
- `logo/AdilCompanyNoFill.png` — نسخة شفافة (الحبر كحلي فقط) — تُستخدم على خلفيات فاتحة بدون كبسولة.
- `logo/AdelSystem V01.png` — نسخة الخط الكحلي الكامل.
- `logo/على دربي On My Path …` — **ليست** هوية هذا المشروع؛ هي شعار منتج فرعي آخر لنفس الشركة (تطبيق ملاحة/توصيل)، أُبقيت في المجلد كمرجع فقط ولم تُعتمد هنا.

## لغة التصميم
الرمز في شعار ADIL يتكوّن من: عقدة/عين دائرية، حرف "D" مفتوح، شرائح سرعة بزاوية 45°، وخطاف "L" أمامي — نفس القواعد الهندسية المستخدمة في شعار "On My Path" (نفس الشركة)، لذلك اعتمدت هذه القواعد في كل عناصر واجهة النظام الجديدة:

| العنصر | القيمة |
|---|---|
| اللون الأساسي (Ink Navy) | `#0B1F3A` |
| لون التمييز (Route Teal) | `#00C2A8` — يُستخدم بحذر: تنبيهات/حالات إيجابية فقط |
| الخلفية | أبيض / رمادي فاتح جدًا `#F5F6F8` |
| الخط | Readex Pro (عربي + إنجليزي) |
| الزوايا | 0° أو 45° فقط، انحناء 2u |
| نصف قطر الأيقونة | 10.5u على شبكة 48u |

## تطبيقها على ألوان الخطورة (Threat Levels)
نحتفظ بالكحلي والأبيض كهوية أساسية، ونضيف ألوان دلالية موحّدة لتصنيف الخطورة في اللوحة (لا تتعارض مع Route Teal):

| المستوى | اللون |
|---|---|
| حرج Critical | `#D7263D` |
| مرتفع High | `#F46036` |
| متوسط Medium | `#F2C94C` |
| منخفض Low | `#00C2A8` (نفس Route Teal) |
| معلومة Info | `#8A94A6` |
